# Repository Guidelines

Guidance for AI coding agents and contributors. The canonical sources are:

- [CLAUDE.md](CLAUDE.md): commands, architecture, conventions, and the security model. Read this first.
- [CONTRIBUTING.md](CONTRIBUTING.md): setup and the pre-PR checklist.

- [docs/README.md](docs/README.md): index of the detailed docs.

Use `pnpm` only (never yarn, npm or `npx astro`). Do not duplicate guidance here; update the files above instead.
