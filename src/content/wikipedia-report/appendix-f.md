<p>In their “Editing for Hate” report, the ADL rarely included references to the Wikipedia edits to which they were referring. We asked ChatGPT to reconstruct the links, and have included them in this appendix as a service to future researchers. Links which we used in the report were hand-verified.</p>
<p>Prompt used:</p>
<ul>
<li><p><em>“Attempt to find all the wikipedia edits (the permalink to the actual change) referenced in the ADL editing for hate article, attached. Also include all removed pages. In each case, find whether the edits were reverted, or the content re-added at a later date (perhaps in a different location). Include whether the content remains in the article (or a replacement article today). In each case, include the author's or editors' explanations for content edit or removal.</em></p></li>
</ul>
<blockquote>
<p><em>Specificity and accuracy are important. Finding each edit is essential. Finding change reversion or content being re-added is obviously more" messy, so include situations where you are unsure but include evidence and qualification.”</em></p>
</blockquote>
<ul>
<li><p><em>“I'd like a table for future researchers, that provides the raw evidence. So a table with the ADL claim, page, wording, and a permalink to the actual wikipedia source. If reversions exist, include those links in the table”</em></p></li>
<li><p><em>“include match certainty”</em></p></li>
<li><p><em>“After that, redo the HTML/md/csv pages, but instead of using ChatGPT summaries of content, use actual quotes”</em></p></li>
<li><p><em>“I want to add this as a table to the report, which is in google docs. Can you format something I can paste in?”</em></p></li>
</ul>
<p><a href="https://chatgpt.com/share/6ae51404-850c-83eb-8976-327f459564cd" rel="noopener noreferrer">For transparency, the entire conversation is available</a>.</p>
